# 🛰️ AI-Based Deforestation Monitoring System

An academic, production-ready Deep Learning and Remote Sensing decision-support platform designed to detect, segment, and quantify deforestation from bi-temporal satellite imagery (Sentinel-2, Landsat, PlanetScope, and GeoTIFF).

## 🌟 Key Features

1. **Multi-Temporal Satellite Change Detection**:
   - Takes two satellite images of the same area: **Time 1 (historical/baseline)** and **Time 2 (current)**.
   - Deep Learning pixel-level forest canopy segmentation using PyTorch **ForestUNet**.
   - Calculates pixel-level canopy loss, percentage deforested, physical area in **Hectares & $km^2$**, and estimated **$CO_2$ carbon stock loss**.
   - Identifies individual disturbance zones using **connected components** with area and confidence per zone.

2. **Real Model Inference vs. Clearly Marked Demo Mode**:
   - **🟢 REAL MODEL INFERENCE**: Automatically enabled when a trained checkpoint (`models/checkpoints/unet_deforestation.pth`) is detected.
   - **🟡 DEMO / MODEL NOT TRAINED MODE**: Enabled when no checkpoint is present (or toggled via sidebar for testing). Estimates canopy via visible-spectrum proxy without pretending to be a trained neural network.

3. **Multi-Format Satellite Image Ingestion**:
   - Supports **PNG, JPG/JPEG, TIFF, and GeoTIFF**.
   - Automatic radiometric scaling (16-bit to 8-bit normalization).
   - Automatic spatial harmonization (resizes/crops differing dimensions without distortion).
   - Displays full metadata: Width, Height, Channels, Format, File Size (KB), Bit Depth, and embedded GSD resolution.

4. **Interactive Dashboard & Multi-Layer Visualizations**:
   - **Satellite & AI Segmentation**: Time 1, Time 2, AI Deforestation Overlay (with adjustable opacity slider), Binary Mask (White = Loss), Model Confidence Heatmap.
   - **Forest Masks & 4-Class Change Map**: Green = Retained, Red = Loss, Blue = Regrowth, Dark = Non-forest.
   - **Interactive Detection Map**: Zoomable/pannable Plotly image-coordinate viewer with bounding boxes, centroids, and hover tooltips, plus Folium satellite basemap when GPS coordinates are available.
   - **Spectral NDVI Explorer**: NDVI calculation and differencing for multispectral bands, with graceful notification if imagery is RGB-only.
   - **Detected Regions Table**: Breakdown of zones by Detection ID, area (ha/px), confidence %, and bounding coordinates.
   - **Executive Audit & PDF Report**: One-click download of high-resolution PDF audit report generated via ReportLab with mandatory legal/environmental disclaimer.

5. **Model Benchmarks & Comparison**:
   - Non-fabricated quantitative metrics on 30 test patches: Accuracy, Precision, Recall, F1/Dice, and IoU.
   - Displays `"Not evaluated"` for un-trained architectures.

6. **Curated Case Studies & Research Library**:
   - 5 presets: Amazon Basin (Brazil), Borneo (Indonesia), Congo Basin, Cerrado Savannah, and Western Ghats (India).
   - 10 full-text peer-reviewed papers from Nature and PLOS ONE with download buttons, plus an interactive form to add new literature.

## 🌟 Operational Modes: Synthetic Benchmark vs. Real Satellite Data

The system provides two strictly segregated operating workflows:

### 1. 🧪 Synthetic Benchmark Mode
* **Purpose**: Algorithmic verification, UI regression testing, and reproducible academic demonstration.
* **Data Origin**: Procedurally simulated Sentinel-2 multispectral scenes generated by `dataset/generate_dataset.py` with physical reflectance curves (Sentinel-2 VNIR bands).
* **Presets**: 5 curated tropical biomes (Amazon fishbone logging, Borneo agricultural clearcuts, Congo selective logging, Cerrado fire scars, Western Ghats intact control reserve).
* **Honest Labeling**: Clearly flagged as **`🧪 SYNTHETIC BENCHMARK MODE`** across the UI, metrics, and audit exports. Never presented as genuine Earth observations.

### 2. 🛰️ Real Satellite Data Mode
* **Purpose**: Operational deforestation monitoring on genuine Earth Observation imagery.
* **Supported Sensors**:
  * **Sentinel-2 MSI (Level-2A Bottom-Of-Atmosphere Surface Reflectance)**: 10m VNIR bands.
  * **Landsat 8/9 OLI (Collection 2 Level-2 Surface Reflectance)**: 30m multispectral bands.
  * **PlanetScope / Dove (Surface Reflectance Ortho Tiles)**: 3m high-resolution monitoring.
* **Geospatial Import Engine**:
  * Decodes **georeferenced GeoTIFF (`.tif`, `.tiff`)** tags directly via PIL and rasterio (when installed).
  * Validates Coordinate Reference Systems (CRS, e.g. `EPSG:32720`, `EPSG:32619`, `EPSG:4326`).
  * Extracts exact Ground Sampling Distance (GSD) from `ModelPixelScaleTag` (Tag 33550).
  * Computes exact spatial footprint overlap percentage from `ModelTiepointTag` (Tag 33922) and bounding boxes.
  * Screens cloud contamination and cloud shadow artifacts.
  * Preserves multispectral bands (RGB + NIR / SWIR) without destructive RGB down-sampling.
  * Extracts authoritative acquisition timestamps from `DateTime` (Tag 306). Never invents dates.

## 🛰️ Real Satellite Data Specifications & Acquisition Guide

### Data Specifications
| Parameter | Sentinel-2 L2A (Recommended) | Landsat 8/9 OLI (Supported) |
| :--- | :--- | :--- |
| **Product Level** | Level-2A (BOA Surface Reflectance) | Collection 2 Level-2 Surface Reflectance |
| **File Format** | Georeferenced GeoTIFF (`.tif`, `.tiff`) | Georeferenced GeoTIFF (`.tif`, `.tiff`) |
| **Native Ground Resolution**| **10.0 metres / pixel** (B2, B3, B4, B8) | **30.0 metres / pixel** (B2, B3, B4, B5) |
| **Recommended Bands** | Band 4 (Red), Band 3 (Green), Band 2 (Blue), Band 8 (NIR) | Band 4 (Red), Band 3 (Green), Band 2 (Blue), Band 5 (NIR) |
| **Coordinate System (CRS)** | UTM Projected CRS (e.g. `EPSG:32620`, `EPSG:32720`) | UTM Projected CRS or WGS 84 (`EPSG:4326`) |
| **Cloud Cover Tolerance** | **< 10% cloud contamination** | **< 10% cloud contamination** |
| **Bit Depth** | 16-bit integer (scaled by 10,000) or normalized 8-bit | 16-bit integer or normalized 8-bit |

### How to Acquire Free Real Satellite Data
1. **Copernicus Data Space Ecosystem (Sentinel-2)**:
   * Visit: [dataspace.copernicus.eu](https://dataspace.copernicus.eu/) (or Copernicus Browser).
   * Register a free account and define your Area of Interest (AOI).
   * Filter for **Sentinel-2 L2A** with Cloud Cover `< 10%`.
   * Select two distinct observation dates: Time 1 (e.g., dry season baseline) and Time 2 (e.g., post-clearing date).
   * Download the GeoTIFF composite (True Color RGB or 4-band RGB+NIR).
2. **USGS EarthExplorer (Landsat 8/9)**:
   * Visit: [earthexplorer.usgs.gov](https://earthexplorer.usgs.gov/).
   * Select **Landsat Collection 2 Level-2 Surface Reflectance**.
   * Download the surface reflectance GeoTIFF package for matching row/path tiles.

## 🧠 Model Checkpoint Domain Notice & Real Retraining Pipeline

### Domain Notice
The default active model checkpoint (`models/checkpoints/unet_deforestation.pth`) was trained on procedurally simulated Sentinel-2 benchmark scenes (`dataset/train`). While its 4-stage encoder-decoder architecture executes real deep-learning feature segmentation, real-world operational monitoring encounters atmospheric scattering, seasonal phenology, and sensor calibration variations.

When Real Satellite Data Mode is active, the dashboard automatically displays a **Model Domain Compatibility Notice** and points to the retraining module.

### Retraining on Real-World Labelled GeoTIFFs
To train or fine-tune `ForestUNet` on real satellite data (e.g. from OpenForest, ForestNet, or your own labelled GeoTIFF tiles):

```bash
# 1. Train ForestUNet on real satellite imagery from scratch
python -m training.train_real --epochs 10 --batch-size 4 --lr 0.0005 --channels 3

# 2. Fine-tune from the existing benchmark checkpoint for domain adaptation
python -m training.train_real --fine-tune --checkpoint models/checkpoints/unet_deforestation.pth --epochs 5

# 3. Train a 4-channel model (RGB + Near-Infrared)
python -m training.train_real --channels 4 --epochs 8
```

Trained checkpoints are automatically saved to `models/checkpoints/unet_real_forest.pth` with verified provenance metadata.

## 🚀 Quickstart & Setup Guide

### 1. Prerequisites
Ensure Python 3.10+ is installed on your system.

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

### 3. Verify System Pipeline & Run Automated Tests
Run the comprehensive test suites to verify all 16 pipeline stages and 24 forensic audit tests:
```bash
# 1. Run full 24-test unit test suite
python -m pytest tests/test_audit.py -v

# 2. Run 16-stage end-to-end integration verification
python test_system.py
```

### 4. Retrain Models
- **Synthetic Benchmark Training**:
  ```bash
  python train.py --epochs 6 --batch-size 8 --lr 0.001
  ```
- **Real Satellite GeoTIFF Retraining**:
  ```bash
  python -m training.train_real --epochs 8 --batch-size 4 --lr 0.0005
  ```

### 5. Evaluate the Model
Evaluate the trained checkpoint on the independent test set:
```bash
python evaluate.py
```

### 6. Run Multi-Model Benchmarks
Run quantitative comparisons across U-Net, Siamese ChangeNet, Random Forest, and Baseline NDVI:
```bash
python models/run_benchmark.py
```

### 7. Launch the Interactive Dashboard
- **Windows (1-Click Launch)**: Double-click `start.bat`
- **Or via Command Prompt / Terminal**:
```bash
streamlit run app.py
```

## 🛰️ How to Analyze Real Satellite GeoTIFF Imagery

1. In the top selector, switch to **`🛰️ Real Satellite Data Mode (GeoTIFF Sentinel-2 / Landsat)`**.
2. To explore the curated real dataset:
   - Select **"Sentinel-2 L2A GeoTIFF Sample Pair (Rondônia Amazon)"**.
   - The system automatically loads genuine 4-band Sentinel-2 L2A GeoTIFFs (10m GSD, CRS `EPSG:32720`, acquisition dates: 2020-08-15 and 2023-08-20).
3. To analyze your own custom satellite observations:
   - Select **"Import Custom Georeferenced GeoTIFF Images (T1 & T2)"**.
   - Upload your Time 1 GeoTIFF (`.tif` / `.tiff`).
   - Upload your matching Time 2 GeoTIFF (`.tif` / `.tiff`).
   - (Optional) Upload a verified reference ground-truth mask to compute empirical test metrics.
4. Expand **Image Metadata** to inspect:
   - Detected CRS (e.g. `EPSG:32720`, `EPSG:4326`)
   - Verified GSD pixel resolution
   - Spatial bounding box and overlap percentage
   - Cloud contamination screening (< 10% recommended)
   - Spectral bands (RGB + NIR / SWIR preserved)
5. Click **[ANALYZE DEFORESTATION]**.
6. Inspect the results:
   - **Honest Verification Panel**: Reviews checkpoint compatibility, data provenance, CRS alignment, and verified hectare math.
   - **Empirical Ground-Truth Validation**: If a reference mask is provided, displays true empirical IoU, Dice, Precision, and Recall.
   - **Inference Diagnostics**: Deep per-pixel classification breakdown and probability ranges.
   - **Executive PDF Report**: Download the full audit trail report.
