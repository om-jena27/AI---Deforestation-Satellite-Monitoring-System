# Project Guidelines & Rules

## GitHub Synchronization Rule

Whenever any changes (code modifications, new features, bug fixes, documentation updates, or new assets) are completed in this project:
1. **Stage and commit** the modified files with a clear, descriptive commit message.
2. **Push the changes** to the remote repository on GitHub (`origin main`: `https://github.com/om-jena27/AI---Deforestation-Satellite-Monitoring-System.git`).
